ZUBoard 1CG UART 現場展示套件

Avnet ZUBoard 1CG

1 硬體準備(每次重新供電後需確認)

  • BOOT MODE 撥動開關 SW2 設定為 JTAG 模式:ON-ON-ON-ON
  • micro-USB 傳輸線接上 ZUBoard 的 J16(JTAG/UART)並連接到電腦
  • USB-C 15V 電源接上 J15
  • 按下電源鈕 SW7 開機,確認 D23 綠色 LED 亮起

此時 User RGB LED D4、D5 應為熄滅(尚未燒錄任何邏輯)——這正是「燒錄前」的狀態,可先讓客戶觀察一次做對比。

2 燒錄並執行展示程式

雙擊資料夾中的 1_Program_And_Run.bat。

此腳本會自動透過 JTAG 燒錄位元流(bitstream)並啟動應用程式,約需 10~20 秒,終端機視窗顯示 APP_RUNNING 即代表成功。
燒錄完成的瞬間,D4、D5 會立即開始以約 1 秒的頻率交互閃爍(此為 PL 硬體邏輯自動運作,與軟體無關)——不需要任何額外說明,客戶用肉眼就能立刻分辨「燒錄前 / 燒錄後」的差異。

3 即時顯示 UART 輸出(本頁面)

您目前使用的瀏覽器不支援 Web Serial API。請改用 Microsoft Edge 或 Google Chrome(Windows 內建的 Edge 即可,不需額外安裝)。
尚未連線
等待連線... 按下「連線至 ZUBoard」後,於彈出視窗中選擇對應的序列埠(通常只會列出一個選項)。

連線設定:115200 baud、8 資料位元、無同位、1 停止位元(與程式內建設定一致)。

4 系統架構方塊圖(本頁面,無需開啟 Vivado)

下圖即為本範例的系統架構:PS(Processing System)透過 UART0 與電腦通訊,並提供 100MHz 系統時脈給 PL(可程式邏輯)驅動 LED 閃爍電路。

5(選用)在 Vivado 中開啟互動式 Block Design

若客戶想看實際的 Vivado 工具畫面,可雙擊資料夾中的 2_Open_Block_Design.bat,自動開啟 Vivado 並顯示可縮放、可互動的方塊設計圖。

首次啟動 Vivado 可能需要 30~60 秒,建議提前於客戶到場前先執行一次熱機。此步驟並非必要,上方步驟 4 的圖已足夠說明架構。

i 技術組成(開發工具 / 語言 / 函式庫)

目標晶片AMD Zynq UltraScale+ MPSoC — XCZU1CG(內含 Arm Cortex-A53 處理系統 PS + FPGA 可程式邏輯 PL)
硬體設計工具AMD Vivado Design Suite 2026.1 — IP Integrator 建立 PS 方塊設計(system.bd),並以 Verilog 撰寫 LED 閃爍邏輯後整合進同一顆晶片
軟體開發工具AMD Vitis Unified IDE 2026.1(Python API)— 由硬體匯出檔(.xsa)建立 Standalone 平台與應用程式專案
執行環境Standalone(裸機,無作業系統),執行於 Cortex-A53 #0
程式語言C(應用程式邏輯)、Verilog(PL LED 閃爍模組)、Tcl / Python(建置與燒錄自動化腳本)
關鍵函式庫 / 驅動xuartps(UART 驅動)、xil_printf(標準輸出)、FSBL 與 PMUFW(由 Vitis 平台自動產生的開機元件)
燒錄 / 除錯介面JTAG,透過板載 FTDI FT2232H 晶片,以 XSDB(Xilinx System Debugger)+ hw_server 執行下載與啟動
本網頁技術純 HTML5 + CSS3 + JavaScript(Web Serial API)— 不需安裝、不需伺服器,雙擊即可用 Edge / Chrome 開啟

以上皆為 AMD/Xilinx 官方免費工具鏈,元件全數在 Windows 上本機建置與燒錄完成。
